# Design rationale

StudySprint is designed to make everyday student planning feel clear rather than overwhelming. Its goal is to help students capture a few tasks, understand what remains, and give one activity focused attention. The interface uses a calm purple palette, generous spacing, rounded cards, and a clear type hierarchy so the most useful actions are easy to find. The dashboard places progress and the task list first, while the focus timer sits alongside them as a simple supporting tool. Task priorities use restrained colour accents, and the layout changes to a single-column mobile view on smaller screens. The website uses browser storage so tasks remain available after a refresh without requiring an account or exposing credentials. A useful future improvement would be optional cloud sync, allowing a student to access the same task list on multiple devices.
